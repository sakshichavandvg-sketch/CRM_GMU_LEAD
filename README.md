# GMU

This repository contains the GMU project with a Next.js frontend, backend structure, and API contract documentation.

## Project Overview

- Frontend: React + Next.js UI for the authentication flow and application layout
- Backend: Backend folder for server-side implementation
- API Contract: Shared API documentation and contract files

## Project Structure

- frontend/: Main web application
- Backend/: Server-side code and services
- API Contract/: API definitions and documentation

## Getting Started

1. Navigate to the frontend folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open http://localhost:3000 in your browser.

## Notes

- Local environment files such as .env are ignored by Git.
- Build output and dependency folders are also excluded from version control.
